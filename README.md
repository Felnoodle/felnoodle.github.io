# felnoodle.github.io

Portfolio and CV of Joni Dunkel, live at **https://felnoodle.github.io**.

Plain HTML, CSS and JavaScript, no build step.

- `index.html`, `portfolio.css`, `portfolio.js`: the site. Projects, skills and hobbies are data at the top of `portfolio.js`.
- `cv.html`: source of the CV. To update `joni-dunkel-cv.pdf`, open it in Chrome → Print → Save as PDF (A4, margins none, background graphics on).
- `images/`: profile photo and project thumbnails.
